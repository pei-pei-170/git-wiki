# Git password authentication is shutting down（摘錄）

- 原文網址：https://github.blog/changelog/2021-08-12-git-password-authentication-is-shutting-down/
- 發布日期：2021-08-12（GitHub Changelog，頁面標籤為 Retired）
- 原文長度：正文只有兩句重點，加上一句連到另一篇部落格文章的說明。

## 引用句（片段）

> starting on August 13, 2021, at 09:00 PST, we will no longer accept account passwords when authenticating Git operations on GitHub.com

> token-based authentication (for example, personal access, OAuth, SSH Key, or GitHub App installation token) will be required for all authenticated Git operations

## 重點摘要（自己的話）

1. GitHub 宣布，從 2021 年 8 月 13 日太平洋標準時間 09:00 起，在 GitHub.com 驗證 Git 操作時，不再接受帳號密碼。
2. 所有需要驗證的 Git 操作，都改成必須使用以 token 為基礎的驗證方式。原文舉的例子有 personal access token、OAuth、SSH key，以及 GitHub App installation token。
3. 原文另外連到一篇部落格文章，說明要怎麼做才能繼續安全地使用 Git 操作。本專案沒有 ingest 那篇文章。
